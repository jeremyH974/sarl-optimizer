🏖️ Optimiseur de congés : le plan annuel optimal

Salariés et indépendants : avec VOTRE nombre de jours, où les poser pour obtenir le maximum de repos sur l'année : mois par mois.

Le plus important : entrez vos jours de congés (ex. 25) et vos RTT → l'outil calcule les jours fériés (Pâques compris), affiche les vacances scolaires de votre zone (A/B/C) sur le calendrier, et trouve le plan annuel optimal : quels jours poser pour transformer chaque pont en longue pause. 2027 : l'Ascension tombe le jeudi 6 mai.

👷 Pour les salariés : les règles de pose

  • Demandez avant de planifier : l'ordre des départs est fixé par l'employeur : le pont idéal doit être validé à l'avance ;
  • Ouvrés ou ouvrables ? l'outil compte en jours ouvrés (lundi-vendredi) ; certaines conventions comptent en ouvrables (6 jours) : 30 jours/an = 25 ouvrés ;
  • Un férié pendant vos congés n'est pas décompté : poser autour d'un férié = double gain ;
  • Fractionnement : si vous posez moins de 5 semaines entre le 1er mai et le 31 octobre, des jours de fractionnement peuvent s'ajouter (selon convention) ;
  • RTT : si vous avez des RTT, utilisez-les pour « boucher les trous » : ils allongent le pont sans toucher aux congés payés.

📋 Les règles du jeu

  • Les jours fériés ne sont pas décomptés de vos congés (sauf accord contraire) ;
  • L'outil compte en jours ouvrés (lundi-vendredi) : le mode le plus courant ;
  • Une fenêtre = vos jours posés + les week-ends et fériés qui s'y rattachent (le « pont ») ;
  • Le plan annuel répartit votre budget de jours sur les meilleurs ponts de l'année (sans chevauchement).
