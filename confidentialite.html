🔒 Politique de confidentialité

Le plus important : ce site est 100% sans traqueur : pas de cookies, pas de publicité, pas d'analyse de comportement. Vos chiffres (CA, salaires…) restent dans votre navigateur et ne sont jamais transmis.

1. Aucune collecte de données

Le site ne collecte aucune donnée personnelle :

  • Pas de cookies (ni de traceurs équivalents) ;
  • Pas de formulaire de contact (à venir éventuellement) ;
  • Pas de mesure d'audience (à venir : Matomo, auto-hébergé et anonymisé) ;
  • Les calculs des simulateurs s'exécutent entièrement dans votre navigateur : aucune donnée ne quitte votre machine.

2. Données saisies dans les simulateurs

Vos saisies (chiffre d'affaires, charges, salaires…) sont traitées localement par les scripts JavaScript de la page. Elles ne sont ni stockées, ni transmises, ni consultables par quiconque. Il n'existe pas de serveur applicatif.

3. Hébergement et journaux

L'hébergeur (actuellement : machine locale / à terme : GitHub Pages) peut conserver des journaux techniques standard (adresse IP, agent utilisateur, pages consultées) le temps de la connexion, comme tout service web. Ces journaux ne sont pas exploités commercialement.

4. Vos droits (RGPD)

Dans la mesure où aucune donnée personnelle n'est collectée, il n'existe pas de traitement à corriger ou supprimer. Pour toute question relative à vos données, contactez l'éditeur via les canaux indiqués dans les mentions légales.

5. Liens externes

Les pages externes (service-public, URSSAF, BPI, impots.gouv.fr…) ont leurs propres politiques de confidentialité : consultez-les avant d'y saisir des données.
